### Development Workflow

**Branching Strategy:**

All new work (features, bug fixes, improvements) must be done on a new branch checked out from `main`. The only exception is if the current branch is already the correct feature branch for the task.

Branch names should be concise, relevant, and follow a standard convention:
-   `feat/feature-name`
-   `fix/bug-description`
-   `chore/task-description`
